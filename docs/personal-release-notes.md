Personal Bhagavad Gita edition of Attending.

- Replaces the prayer panel, reminders and settings with eight offline daily Bhagavad Gita quotations, verse references, Edwin Arnold attribution, browsing, copy and source links.
- Includes an Apple silicon DMG installer and an alternative ZIP of the app.
- Uses the personal bundle identifier `app.atpresearch.Attending`. Preferences and permission grants are separate from the original app. Upstream automatic updates are disabled; install future personal releases manually.

Requires **Apple silicon (M1 or newer)** and **macOS 14.2 or later**. Quit any running Attending, open the DMG, drag Attending into Applications, then launch it there.

This personal build is **ad-hoc signed and not notarized by Apple**. If macOS blocks opening it, go to **System Settings → Privacy & Security → Open Anyway** for Attending and confirm.

Validation includes the release build, core/bridge/approval/fake-transport checks, bundle signature verification, DMG integrity and mounting, and launching the packaged app's diagnostic mode. Interactive use, permissions and live external accounts still require testing on your Mac. Minimum-version compatibility was not separately tested on macOS 14.2.

The build manifest identifies the exact source commit, architecture, bundle ID and signing status. `SHA256SUMS.txt` provides download checksums.
